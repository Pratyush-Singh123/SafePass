## 📌 Problem Statement

> **TravelTech**: *Real-Time Crisis Communication for Tourists During Extreme Weather Events*

* **Context**: When localized extreme weather events occur—such as sudden flash floods or severe cyclones—foreign tourists are highly vulnerable due to their lack of local geographic knowledge and language barriers.
* **Problem**: Local weather warnings, emergency broadcasts, and safe-zone declarations are fragmented and rarely translated or localized for tourists. Travelers struggle to verify which areas are actively flooded or unsafe and cannot easily access translated instructions from local authorities, forcing them to rely on chaotic, unverified social media rumors.
* **Impact**: This communication gap leads to widespread panic, stranded travelers wandering into high-risk weather zones, and unnecessary strain on local rescue services during critical windows.

---

## 💡 Solution: SafePass

**SafePass** is an offline-first, mobile-responsive crisis companion that bridges tourists, local disaster responders, and diplomatic embassies:

1. **🗺️ Geospatial Evacuation Navigator**: Interactive Leaflet maps rendering dynamic storm surge hazard zones, safe corridors, and 20 verified high-ground relief shelters.
2. **💬 Multilingual AI Assistant**: Empathetic psychological crisis triage with AI chat in 7 languages (English, French, German, Spanish, Japanese, Hindi, Tamil) with box-breathing regulation and offline 2G SMS distress fallback.
3. **🏛️ Consular Command Center (`/admin`)**: Restricted embassy & TNDMA liaison portal tracking foreign citizen safety manifests, Red Zone search-and-rescue triage, and mass consular advisories. *(Demo Credentials: Username `admin` | Password `admin@123`)*
4. **👨‍👩‍👧 Zero-Friction Family Status Link (`/status`)**: Public read-only verification link with live safety status, device telemetry, and 1-tap WhatsApp alert for families abroad.

## 🚀 Local Development Setup

### Prerequisites
* **Node.js** (v18.0 or later)
* **npm** (v9.0 or later)

### Quick Start

```bash
# 1. Clone repository
git clone https://github.com/Pratyush-Singh123/SafePass.git
cd SafePass

# 2. Install dependencies
npm install --legacy-peer-deps

# 3. Start development server
npm run dev
```

The application runs locally at `http://localhost:5173`.

### Production Build

```bash
npm run build
npm run preview
```
